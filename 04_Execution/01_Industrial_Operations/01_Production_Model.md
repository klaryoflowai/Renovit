# Production Model

## Phase 1 industrial flow

1. selectie calcar alb / faina calcaroasa Volodeni
2. transport intern / extern la punctul de procesare
3. micronizare / sortare granulometrica
4. dozare aditivi + mixare uscata
5. ambalare 20/25kg
6. depozitare uscata
7. distributie
