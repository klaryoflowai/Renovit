# Supplier Questions

## RFQ scurt pentru furnizori

```text
Salut,

Caut linie completa pentru gleturi / tencuieli pe baza de calcar:

- moara micronizare 5 t/h, finete tinta sub 100 microni
- sita / classifier pentru fractii 0.1-2 mm
- mixer 2 t cu dozatoare pentru 4 componente
- linie ambalare reglabila 20/25kg, interval 15-30kg, aproximativ 600 saci/h
- capacitate tinta fabrica: 10.000 t/an produs finit

Buget tinta pentru scenariu hibrid: 400-500k EUR pentru core equipment, inainte de confirmarea infrastructurii existente.
Livrare: Moldova.
Va rog oferta tehnica + comerciala, termen livrare, garantie, instalare, commissioning si referinte.
```

## RFQ discipline

Nu intrebam doar "cat costa?". Cerem oferta pe flux complet si marcam clar ce este exclus.

## First questions

1. Care este capacitatea reala in t/h pentru material similar?
2. Ce an de fabricatie are echipamentul?
3. Cate ore de lucru are?
4. Exista video cu linia pornita?
5. Exista documentatie tehnica?
6. Ce include pretul?
7. Ce nu include pretul?
8. Cine face demontarea?
9. Cine face transportul?
10. Cine face instalarea si commissioning-ul?
11. Ce consum energetic / combustibil are?
12. Ce piese critice trebuie inlocuite?
13. Care este costul estimat de reparatii?
14. Exista garantie?
15. Exista referinte de clienti?
16. Poate lucra cu specificatia noastra de materie prima?
17. Ce calitate / finete poate livra?
18. Poate scala modular sau devine bottleneck?
19. Linia poate ambala stabil atat 20kg, cat si 25kg?
20. Ce precizie de dozare garanteaza pentru aditivi si pentru sac?
21. Ce finete garanteaza pentru calcar / CaCO3 si la ce consum energetic?
22. Ce teste de acceptanta se pot face inainte de plata finala?
23. Ce cost estimat are transportul pana in Moldova?

## Required attachments

- oferta tehnica
- oferta comerciala
- poze / video
- schema electrica
- consumuri
- lista piese
- conditii garantie
- conditii livrare
- cost instalare
- termen livrare
- conditii de acceptanta / test run
