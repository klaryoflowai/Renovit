# Execution System Scaling Up

## Purpose

Executia in RENOVIT inseamna disciplina de rulare a unui business industrial:

- cariera
- procesare
- calitate
- logistica
- distributie
- decizii
- riscuri
- readiness

Nu folosim modelul de `service delivery` din BioStream pentru ca aici fluxul este industrial, nu bazat pe servicii pe teren.

## Rule

Executia nu inseamna doar "a face".

Inseamna:

`data -> decision -> owner -> deadline -> review`
