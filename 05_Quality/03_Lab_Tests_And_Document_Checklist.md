# Lab Tests And Document Checklist

## Mandatory chemistry request

Cerem obligatoriu o analiza de laborator cu:

```text
CaSO4·2H2O = ____ %    target intern phase 1: >= 90%
SiO2 = ____ %          target intern: <= 3%
Fe2O3 = ____ %         target intern: <= 0.5%
MgO = ____ %           target intern board screen: <= 1%
Al2O3 = ____ %
```

## Working technical tests to ask for

- finete de macinare / reziduu pe sita 0.2 mm
- timp de priza / intarire
- rezistenta la compresiune pentru produsul relevant, daca exista teste
- culoare / aspect / consistenta loturilor
- observatii privind variatia dintre probe si loturi

## Sampling discipline

Nu cerem doar un PDF de laborator.

Cerem si:

- data prelevarii
- locul / zona de prelevare
- cine a prelevat proba
- daca exista probe din mai multe zone ale carierei
- daca analiza este reprezentativa pentru ceea ce se extrage real acum

## Mandatory documents to request

- [ ] analiza chimica recenta, semnata de laborator
- [ ] identificarea probei si data prelevarii
- [ ] studiu geologic relevant
- [ ] orice test pe produs finit sau semi-produs
- [ ] daca exista, documentatie de performanta pentru produse deja vandute
- [ ] daca au vandut in RO / UE, orice DoP / CE / test report relevant

## Working technical benchmarks

Acestea sunt benchmark-uri interne de screening si trebuie validate cu laboratorul / procesul:

- reziduu pe sita 0.2 mm: `<= 8-12%`
- timp de priza: trebuie masurat pe produsul tinta, nu presupus
- rezistenta la compresiune: trebuie masurata pe produsul final, nu inferata doar din puritate

## Meeting rule

Fara copie de analiza sau fara promisiune clara de trimitere in 48h, subiectul calitatii ramane `unsupported`.
