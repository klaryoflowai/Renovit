# Lab Tests And Document Checklist

## Mandatory chemistry request for limestone route

Cerem obligatoriu o analiza de laborator cu:

```text
CaCO3 = ____ %         target intern premium route: cat mai sus, de preferat >= 93-95%
SiO2 = ____ %          target intern: cat mai jos si stabil intre loturi
Fe2O3 = ____ %         urmarim minimizarea impactului pe alb / culoare
MgCO3 = ____ %
MgO = ____ %
Al2O3 = ____ %
umiditate = ____ %
grad de alb = ____     cu metoda de test clar mentionata
```

## Working technical tests to ask for

- granulometrie / distributie particule pentru fiecare fractie relevanta
- finete pentru filler ultrafin, nu doar reziduu generic pe sita
- umiditate si comportament la depozitare
- densitate aparenta
- culoare / grad de alb / consistenta loturilor
- contaminanti vizibili sau metalici, daca exista risc operational
- absorbtie apa si comportament la amestec, unde este relevant

## Product-specific pilot tests to ask for

- glet mineral: lucrabilitate, consum de apa, aderenta, aspect dupa uscare, slefuire, fisurare, rezistenta daca reteta o cere
- decorativa minerala: fractii granulometrice, textura finala, aderenta, absorbtie apa, permeabilitate la vapori, comportament la aplicare
- mortar ETICS: aderenta, lucrabilitate pe verticala, retentie apa, comportament in strat armat, absorbtie, vapori si alte teste relevante familiei reale de produs

## Sampling discipline

Nu cerem doar un PDF de laborator.

Cerem si:

- data prelevarii
- locul / zona de prelevare
- cine a prelevat proba
- daca exista probe din mai multe zone ale carierei
- daca analiza este reprezentativa pentru ceea ce se extrage real acum

## Mandatory documents to request

- [ ] analiza chimica recenta, semnata de laborator
- [ ] metoda de test pentru grad de alb / culoare
- [ ] identificarea probei si data prelevarii
- [ ] studiu geologic relevant
- [ ] orice test pe produs finit sau semi-produs
- [ ] orice reteta pilot testata intern sau extern
- [ ] daca exista, documentatie de performanta pentru produse deja vandute
- [ ] daca au vandut in RO / UE, orice DoP / CE / test report relevant

## Working technical benchmarks

Acestea sunt benchmark-uri interne de screening si trebuie validate cu laboratorul / procesul. Pentru calcar nu ne mai bazam pe un singur indicator, ci pe combinatie de:

- `CaCO3`
- grad de alb
- stabilitate granulometrica
- umiditate
- consistenta intre loturi

Timpul de priza, aderenta si rezistenta se masoara pe produsul final sau pe lotul pilot, nu se infereaza doar din analiza materiei prime.

## Meeting rule

Fara copie de analiza sau fara promisiune clara de trimitere in 48h, subiectul calitatii ramane `unsupported`.
