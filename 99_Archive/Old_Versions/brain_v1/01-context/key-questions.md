# Key Questions

Acestea sunt intrebarile la care vault-ul trebuie sa raspunda clar.

## Fezabilitate

- Exista avantaj economic real din materia prima proprie?
- Produsul de start corect este tencuiala gips ambalata?
- CAPEX-ul necesar este proportional cu oportunitatea?

## Piata

- Exista cerere reala si recurenta in Moldova?
- Are sens extinderea in Romania din faza 1 sau doar ulterior?
- Ce competitor stabileste pretul psihologic al pietei?

## Operatiuni

- Capacitatea carierei si a liniei permit un business scalabil?
- Care este cel mai mare blocaj operational?
- Ce echipa minima este necesara pentru faza 1?

## Parteneriat

- Ce forma de implicare maximizeaza upside-ul si minimizeaza riscul?
- Care este structura corecta de equity, control si responsabilitate?

## Output dorit

Toate concluziile din vault ar trebui sa contribuie la raspunsuri clare pentru aceste intrebari.
