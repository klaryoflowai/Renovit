## Cele 4 dimensiuni

### 1. Fezabilitate tehnica

- calitatea resursei permite produsul tinta
- infrastructura minima exista
- linia de procesare poate fi implementata realist

### 2. Fezabilitate comerciala

- pretul acceptat de piata este suficient
- canalele de distributie sunt accesibile
- exista loc pentru intrarea unui jucator nou

### 3. Fezabilitate operationala

- echipa minima poate fi construita
- logistica este sustenabila
- capacitatea poate sustine targetul de vanzari

### 4. Fezabilitate financiara

- marja este sanatoasa
- cash flow-ul sustine payback-ul
- downside-ul este suportabil
