# Assumption Summary

## Core Assumptions

- materialele de finisaj pe baza de calcar Cupcini sunt produsul corect de intrare
- formatul trebuie modelat per produs: glet 20kg, granule decorative 25kg, filler micronizat 25kg / vrac
- materia prima proprie ofera avantaj real de cost
- Ocnita sustine 70-80% din masa procesata prin volum si logistica; Volodeni aduce componenta de alb si diferentiere
- fillerul micronizat trebuie sa fie principalul motor de volum, nu produsul secundar
- piata poate absorbi un jucator nou doar daca exista dovezi reale: preturi validate, lead list nominala, competitori cartati si clienti pilot discutati
- partenerul poate sustine financiar faza 1
- logistica si distributia nu distrug marja
- overhead-ul unei operatiuni de `10kt/an` este mai aproape de `12k-18k EUR/luna` decat de `8k EUR/luna`
- `1.500 t/luna` trebuie tratat ca scenariu de scalare spre `~18 kt/an`, nu ca baseline automat de lansare

## Assumptions Requiring Validation

- costul real de extractie / tona si regula de transfer pricing intre mina si RENOVIT
- randamentul real al micronizarii / sortarii / mixarii
- pretul angro real pe fiecare produs in piata MD / RO
- volumul de cerere real pe segment si pe produs
- termenele de plata reale si discounturile comerciale pe canal
- lista reala de competitori, produse comparabile si nivel de penetrare in MD / Nord / Balti / Chisinau
- CAPEX-ul real pentru linia minima de materiale de finisaj
