# RENOVIT Project Charter

## Mission

RENOVIT are misiunea sa construiasca o divizie profitabila de materiale de finisaj pe baza de calcar alb / calcar-travertin din ecosistemul S.A. Mina din Cupcini.

## Phase 1 Objective

Sa validam rapid, cu risc controlat, ca modelul produce marja sanatoasa si cash flow pozitiv din:

- materie prima proprie
- retete certificate pentru materiale de finisaj
- micronizare / sortare / mixare / ambalare eficienta
- distributie comerciala reala pe preturi angro validate

## Business Thesis

Modelul este atractiv doar daca functioneaza simultan 4 lucruri:

1. costul real de productie este semnificativ sub pretul acceptat de piata
2. reteta finala poate fi certificata si repetata lot dupa lot
3. produsele de start pot fi vandute constant prin distributie reala
4. parteneriatul ofera control si upside suficiente pentru executie serioasa

## Initial Strategic Choice

Stage 1 merge pe model lean:

- fara diversificare prematura
- focus exclusiv pe materiale de finisaj si intermediare minerale: glet mineral de baza 20kg, granule decorative selectate 25kg si filler micronizat alb 25kg / vrac
- folosirea avantajului structural al calcarului alb local si al volumului Ocnita
- accent pe marja si validare, nu pe volum fortat
- maximizarea resursei proprii inaintea retetelor dependente de chimie externa

## First 90 Days Success Criteria

- costul real / sac si / tona este confirmat pentru fiecare produs
- pretul real angro este confirmat prin distribuitori
- retetele si standardele aplicabile sunt mapate
- un scenariu financiar baza este completat
- structura de parteneriat este clarificata
- verdictul Go / No-Go poate fi luat cu incredere

## Non-Negotiables

- fara CAPEX mare inainte de validarea economica
- fara afirmatii "premium / eco / CE-ready" fara teste si documentatie
- fara dublu limbaj intre "consultanta" si "parteneriat"
- fara asumarea operarii fara drepturi clare de decizie
- fara amestec de ipoteze si cifre validate
